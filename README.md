# 🔊 Voice Assistant for Windows (JARVIS-Inspired)

A Python-based voice assistant inspired by JARVIS from the Iron Man series. This project enables basic task automation on Windows using voice commands, providing a hands-free, interactive experience.

## 🧠 Features

- 🎤 Voice command recognition (e.g., open apps, search Google)
- 🗣️ Text-to-speech responses
- 🕒 Tells current time and date
- 🌐 Opens websites on command
- 🎶 Plays music from your system
- 👋 Personalized greetings and user interaction

## 🛠️ Technologies Used

- **Python**
- `speech_recognition` – for processing voice commands
- `pyttsx3` – for text-to-speech
- `datetime`, `os`, `webbrowser` – for system operations
